🌦️ **ESP32 IoT Weather Monitoring Dashboard**

A real-time weather monitoring system using ESP32 and a DHT22 temperature and humidity sensor. Sensor readings are sent to Firebase Realtime Database and displayed on a responsive web dashboard that can be accessed from mobile or desktop.

**Technologies Used:**
- ESP32
- DHT22 Temperature and Humidity Sensor
- Arduino C++
- Firebase Realtime Database
- HTML, CSS, and JavaScript
- GitHub Pages
- Wokwi Simulator

**Features:**
- Real-time temperature monitoring (°C)
- Real-time humidity monitoring (%)
- Cloud-based data storage using Firebase
- Live web dashboard updates
- Mobile-friendly interface
- Hardware simulation using Wokwi

**Project Goal:** To build a low-cost IoT weather monitoring system that connects sensors, cloud storage, and a web dashboard.
